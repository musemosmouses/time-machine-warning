One original warning label for a time machine, written in the straight-faced voice of a genuine safety notice — the label that turns meeting your own duplicate into a petty debt problem.

> WARNING: Do not meet yourself. If you do, never lend yourself money — you still owe you from last time.

## Run

```sh
node main.ts
```

This writes the entry to `out/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). The program is deterministic: no network, no clock, no randomness. The entry is 103 characters, within the 120-character cap.
